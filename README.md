# ZoomOBS — автоматическая запись пар

Программа для Windows: по расписанию сама заходит на занятия в Zoom (веб-версия) и Mirapolis (VirtualRoom) через Chrome и записывает их через OBS.

## Что умеет

- Расписание пар с верхней и нижней неделями, вкладка «Время пар».
- Вход в Zoom под заданным именем с выключенными микрофоном и камерой. Вход в Mirapolis по ФИО, включая заставку «Начать работу».
- Цепочка конференций Zoom в одной ссылке, по одной на строку. Между конференциями запись встаёт на паузу, и всё пишется в один файл.
- Обрыв конференции: пауза записи и переподключение раз в минуту.
- Затянувшаяся пара: запись продолжается до конца конференции, но не дольше заданного предела (по умолчанию 15 минут).
- Если у следующей пары та же ссылка, программа не переподключается, а только перезапускает запись.
- Переименование файлов записей OBS по шаблону `{name} {date} {time}`.
- Режим «Zoom по очереди» для конференций, которые идут друг за другом без расписания.

## Запуск

Нужны Google Chrome и OBS Studio. В OBS назначьте горячие клавиши записи такие же, как во вкладке «Настройки».

- **Из исходников:** Python 3.12+, запустите `run.bat`. Он сам поставит `websocket-client` и откроет `app.pyw`.
- **Exe:** соберите командой
  ```
  pip install pyinstaller websocket-client
  pyinstaller --onefile --noconsole --name ZoomOBS app.pyw
  ```

## Где хранятся данные

Настройки, ссылки и расписание лежат в `config.json` рядом с программой, а профиль Chrome в папке `chrome-zoom-profile`. Оба в `.gitignore`, потому что в них ваши личные ссылки с паролями и входы.

## Файлы

- `app.pyw` — окно программы (Tkinter).
- `engine.py` — логика: Chrome через DevTools Protocol, Zoom и Mirapolis, OBS, расписание.
- `run.bat` — запуск из исходников.
